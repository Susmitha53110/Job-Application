# Efficiency rules + quality guard

Added: 2026-11-12. Adds to existing Memory — schedule, 20–25/day ramp, 12 tailoring rules, standing answers, Citi/Optum exclusion, no-review submit unchanged.

## Goal
Fewer tokens via reuse; **quality and accuracy always win**.

## Reuse (1–5)
1. Tailor from `memory/MASTER_FACTS.md` (not full resume each time). Re-read resume only if facts drift.
2. Reuse ATS kits under `applications/ats-kits/` (Greenhouse, Lever, Workday, Ashby, iCIMS). Re-check only if form changed.
3. Never re-open/re-score jobs already in `memory/SEEN_JOBS.md` / `memory/APPLIED_INDEX.md`.
4. Tailor from base template: change **only** summary, bullet order, skills order.
5. Scores / catch notes / gaps live in files — do not repeat in chat.

## Keep cheap (6–12)
6. Prefer page text / form fields over screenshots; Computer Use only when needed.
7. Max **2 retries** / step · ~**25 actions** / application → then `needs me`, move on.
8. **One** job search at 08:00 CT → build queue → work it; search again only if queue empty.
9. Fast-skip on title / location / seniority / Citi|Optum before full JD.
10. Interview prep only if score ≥ 8; keep short.
11. Short chat; no step-by-step narration.
12. Outside 08:00–12:00 CT: **do nothing**. One recurring 08:00 CT timer only.

## Quality guard (overrides 1–12 on conflict)
Every application still gets full: JD tier + dealbreakers + honest scores (a/b/c); all **12** tailoring rules; accurate form fill from resume + standing answers; submit + confirmation proof (`unconfirmed` if none); honor schedule, exclusions, daily limit, needs-me. **Never** skip/guess to save usage.

## Usage safety
- If Susmitha says weekly usage **>85%** → cut to **10 applications/day** until reset.

## Daily volume
- Ramp **20–25 applications** per 08:00–12:00 CT window (from 2026-11-13).

## Daily report (by 12:00 CT)
Applied · unconfirmed · skipped · needs me · additions awaiting approval · top 5 missing keywords · succeeded vs asked · `steps shortened for efficiency: [list|none]` · usage note (high/normal/low).
