# Hard rules (always)

## Resume source of truth
- The file in `resumes/base/` is the **only** source of truth.
- Never invent employers, titles, dates, skills, certifications, or metrics.
- Never inflate years of experience.

## Resume tailoring — all 12 rules, every job
1. **TIER THE JD.** Separate required vs preferred. List dealbreakers first: sponsorship/visa, citizenship/clearance, travel %, on-site location, required certifications, required years. If a dealbreaker fails → skip + log why.
2. **REWRITE THE SUMMARY** in the JD's own terms. Lead with what the JD cares about most. Every claim must trace to the base resume. Do **not** change headline, job titles, or section headings.
3. **REORDER BULLETS, NEVER REWRITE FACTS.** Most JD-relevant bullets to the top under each job. Wording stays identical. Exception: delete internal drafting notes and tell Susmitha.
4. **REORDER AND RELABEL SKILLS** to match JD vocabulary. Only real skills from the resume.
5. **MISSING SKILLS.** Hedged additions ("familiarity with," "working knowledge of," "exposure to") only once per skill, never as hands-on. Always build **(a)** reorder-only and **(b)** reorder + hedged. **Submit (a)** unless Susmitha approved (b). Flag every addition as `verify before applying`.
6. **SCORE THREE STAGES** with weighted JD rubric (3 = hard req, 2 = important, 1 = nice-to-have): (a) original, (b) reorder-only, (c) with hedged additions. List TOP 5 MISSING JD KEYWORDS from original resume; say which tailored covers honestly vs remain gaps. **Apply only if honest score (b) ≥ 7/10.**
7. **XYZ BULLETS ONLY WITH REAL NUMBERS** from Memory metrics. Never invent/estimate/imply metrics. Otherwise keep original wording.
8. **VISUALLY CHECK.** Build Word `.docx`. Target ~2 pages; no orphaned headers/awkward breaks. If cannot render, say so in the log. Deliver `.docx` only unless app requires PDF.
9. **ATS-READABILITY CHECK.** No tables, text boxes, multi-column, images/icons, no content in headers/footers; contact in body. Extract plain text and confirm order: name → contact → summary → each employer (dates + title) → skills → education. State what was checked. Never claim "100% ATS compatible."
10. **CATCH NOTE** every job: stretch, must-be-true before applying, dealbreakers (location, sponsorship, travel, pay vs current), what to remove if cannot back up in interview.
11. **NEVER INFLATE.** If JD needs more years than available, say so and call it a stretch. Flag timeline issues (overlapping dates, gaps).
12. **INTERVIEW PREP** for scores ≥ 8/10: 3 hardest technical questions + model answers (~100–160 words, short spoken sentences) from real background only. Bridge from real experience; never claim lacking skills. If answer needs unproven facts, give correct facts and note Susmitha should explain in her own words.

## Application rules
- Save as `[FirstName]_[Company]_[Role].docx` under `resumes/tailored/YYYY-MM-DD/`.
- Fill forms using only MASTER_FACTS + FORM_ANSWERS (+ resume if facts drift).
- Sponsorship: **No**. Multi-year without sponsorship: **Yes**. Auth to work US: **Yes** (F1-OPT). Salary: **120000**. EEO/background: FORM_ANSWERS.
- **STOP → `needs me`** only for uncovered questions, CAPTCHA/2FA after 2 tries, or anything unsure. Never guess.
- Submit directly (no review). Confirmation proof required; else `unconfirmed`.

## Hard constraints
- Never pay for anything or create a paid account.
- Never ask for or store passwords. Susmitha logs into sites herself.
- CAPTCHA / 2FA / account lock → `needs me`, move on. Max 2 retries · ~25 actions/app.
- On error: say so. Never silently skip or report done when not.
- If usage >85% weekly → 10 apps/day until reset.

## First run only
- Dry run on **3** jobs.
- Show tailored resume, score table, catch note, and filled application **before** submitting.
- **Wait for approval**, then start normal daily schedule.
